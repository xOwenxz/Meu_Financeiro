# Meu Financeiro

Dashboard local feito em Python, sem bibliotecas externas. Permite registrar receitas e despesas, acompanhar o resultado mensal, ver o saldo acumulado e comparar os gastos por categoria.

## Como abrir

1. Tenha o Python 3 instalado.
2. Abra o terminal nesta pasta.
3. Execute `python appfinanceiro.py`.
4. Acesse `http://127.0.0.1:8000` no navegador.
5. Para encerrar o servidor, volte ao terminal e pressione `Ctrl+C`.

Os lançamentos são guardados no arquivo `transacoes.json`, criado automaticamente nesta pasta quando você salvar o primeiro registro. Para fazer uma cópia dos dados, copie esse arquivo.
